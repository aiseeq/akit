# tk: --text принимает «Постановка» и «Чем проверить», lint ловит пустую «Приёмку»

Статус: открыт

## Вход
- Проблема: work-admin 28.10 00:06 CET: `tk new --text` с «## Постановка» и «## Чем проверить» (разделы прежнего шаблона) положил их отдельными разделами после пустой «## Приёмка»; `ls` показал no-check, `lint` — ok. Пример — ~/work/docs/tasks/20261028-0006-MEDIUM-jira-review-thursday.md (журнал).
- Метод: имена прежнего шаблона — синонимы: «Постановка» → «Вход», «Чем проверить» → «Приёмка»; no-check — когда ни один из разделов проверки не заполнен; lint называет пустую проверку, как ls.
- Дешевле: нет.
- Инструмент: `cmd/tk`.
- Цена: минуты.
- Если не делать: тикеты с проверкой в чужом разделе, ls и lint расходятся.

## Что сделать
1. `parseTicketSections`: «## Постановка» → «## Вход», «## Чем проверить» → «## Приёмка».
2. `noCheck`: true, только если раздел проверки есть и все такие разделы пусты.
3. `lint`: «empty Приёмка» у тикета со строкой статуса, где noCheck.
