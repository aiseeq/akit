## Что сделать
1. `tk done`: если `session()` не пусто и отличается от --by (без учёта регистра), строка журнала — `<время> готово — <by> (session <session>): <check>`. `completion()` отдаёт checker без хвоста ` (session …)` и отдельно сессию; в taskJSON поле `checker_session`. Сессия равна исполнителю (без учёта регистра) — `done` не отказывает (правило решает лид), но печатает в stderr предупреждение `tk: self-check: session X is the executor`; `tk lint` даёт находку `<путь>: self-check by session X (executor X)` для последней строки «готово» с такой сессией. Старые строки без `(session …)` — не находка.
2. `tk archive --root DIR`: как `ls --root` — DIR и его репозитории первого уровня; каждый репозиторий архивирует свои `docs/tasks` в свой `docs/tasks-archive`; вывод — число и пути относительно DIR.
3. `tk done` с пустой «Приёмкой» (или «Чем проверить») — отказ, ненулевой код, `tk: empty Приёмка: fill it before done`; тикет не меняется.
4. `tk ls --json` — checker, check и checker_session у всех (не только в show). `tk ls --slug PREFIX` — только тикеты, чей slug начинается с PREFIX (без учёта регистра), работает и с --json, --root, --all.
5. `tk -h` и README раздела tk — новые флаги и поведение.
