## Вход
- chooks-master 30.10 ~05:40: pgrep_ancestors держит свой разбор -c (shellCommandScript) и карту «байт значения → байт исходника» (scriptSource), потому что у вызовов вложенного скрипта Offset −1. Просьба — вариант А: Offset вложенных вызовов в координатах исходной команды, когда скрипт — одно слово (литерал, '…', "…").

## Что сделать
1. word: вместе с текстом скрипта — карта pos[i] = смещение в исходной команде байта i текста (−1, если такого байта нет: $'…', склейка ssh). Одна функция снятия экранирования с картой для "…" и для слов без кавычек; прежние unescapeDouble/unescapeBare — через неё.
2. parseNested получает карту: Offset вложенного вызова = pos[Offset], иначе −1. `bash -c`, `ssh host …` (слова через пробел; пробел-разделитель −1), heredoc-скрипт оболочки (тело — срез исходника, карта тождественная от начала тела). Вложенность любой глубины — через ту же карту.
3. Комментарий к Call.Offset и README.
