# busy: память по PSI, подкачка только подтверждением

Статус: готово
Исполнитель: akit-master

## Вход
- Проблема: `busy` (правило `pressure.Rule`) считает машину занятой при подкачке > 1024 KB/s. Подкачка идёт и без нехватки памяти: днём (09–23) она выше 1 МБ/с в 265 из 756 десятиминутных замеров (35%), сейчас 5,5 МБ/с при PSI памяти 0,38%. Ложное «занята» держит очередь graft и будит aguard.
- Метод: замер по sar (`/var/log/sa/sa19..sa27`, `sadf -T -d … -q PSI` и `-W`, 1294 замера по 10 минут; выборка — `~/.cache/akit-accept/sar-mem-swap-1019-1027.csv`: время; smem% за интервал; some avg10; fmem% за интервал; full avg10; подкачка KB/s; доступно ГБ).
- Дешевле: поднять порог подкачки — не различает: в эпизодах давления памяти (some avg10 12–25%, ночь 25–27.10, 26.10 13:10) подкачка 2,8–6,2 МБ/с, то есть столько же, сколько в спокойное время (p90 2,8 МБ/с).
- Инструмент: `akit/pressure`, `cmd/busy`; потребители — graft (очередь heavy), aguard.
- Цена: правка пакета и команды, около часа.
- Если не делать: машина «занята» треть дня без причины.

## Замер
- some avg10: p50 0, p90 0,11, p99 3,55, max 25; ≥ 10 — 5 замеров из 1294, ≥ 5 — 8. full avg10 ≥ 10 — 5, ≥ 5 — 7.
- Все 5 замеров some avg10 ≥ 10 — с подкачкой ≥ 2,8 МБ/с: подтверждение подкачкой их не теряет.
- Жалобы пользователя: 21.10 ~22:00 «кто-то выжрал всю оперативу» — some за 10 минут 0,97%, подкачка 22,6 МБ/с (максимум суток), доступно 6 ГБ; 22.10 ~22:40 «подтормаживает» (виноват оказался Chrome) — some 0,2%, подкачка 2,6 МБ/с; 25.10 09:31 «тормозов нет» при высокой CPU — some 0,52%, подкачка 4,8 МБ/с.
- Ограничение: sar пишет раз в 10 минут, avg10 — мгновенная точка, всплеск между замерами не виден.

## Что сделать
1. Мера «memory» вместо «swap»: занята, если PSI памяти some avg10 > MaxMemSome (по умолчанию 10%) и подкачка за окно > MaxSwapKBs (1024 KB/s, только подтверждение). Подкачка одна — не «занята».
2. Порядок проверок: cpu, io, memory. Нет `/proc/pressure/memory` — sentinel `ErrNoMemPressure`, мера пропущена (как IO).
3. `busy`: строка показывает PSI памяти и подкачку; флаг `--mem-some N`.
4. Порог согласовать с graft-master; ответ — в журнал.
5. Релиз akit, graft-master и aguard-master — версия.

## Приёмка
- Тесты `pressure`: подкачка 5 МБ/с при some 0,4 — свободна; some 12 при подкачке 3 МБ/с — занята по memory; some 12 без подкачки — свободна; нет файла memory — пропуск с `ErrNoMemPressure`.
- `busy` на этой машине сейчас — `free` при подкачке выше 1 МБ/с.
- `graft gate` зелёный.
