# wfor --new: неполная строка до старта не засчитывается

Статус: открыт

## Вход
- Находка 4 критика ТЗ: `wfor line … --new` по `wfor -h` — «only lines appended after the start count», а незавершённая последняя строка, бывшая в файле до старта, не пропускается: её дописанный хвост засчитывается, cmd/wfor/cond.go:142 (`end` — до последнего `\n`).

## Что сделать
- Тест (красный): файл «old-DONE» без `\n`, wfor `--new` на DONE, дописать «\n»; совпадения быть не должно. Ещё: дописать «X\n» к неполной строке «DON» с `--new` на «DONX» — не засчитывать.
- Фикс: при `--new` пропускать и неполную последнюю строку целиком (до её `\n`), справку оставить.

## Приёмка
- Новый тест красный до фикса, зелёный после; `go test ./cmd/wfor` зелёный.
