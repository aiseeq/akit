# akit — консольные утилиты для агентов

Прочитать перед работой: `~/.claude/tools/akit/design.md` (приватный, вне репо) — замысел, грань «утилита в akit или отдельный проект», список утилит, принятые решения. Решения оттуда не пересматривать молча — только обсудив с пользователем; новые решения с источником писать туда, не в репо.

## Правила
- ПУБЛИЧНАЯ РЕПА — БЕЗ ВНУТРЕННЕГО: в коде, тестах, комментариях, README и сообщениях коммитов нет цитат и дат обсуждений, имён сессий и агентов, id транскриптов, домашних путей, имён закрытых проектов, работодателя и людей. «Почему» в комментарии — нейтрально, по сути. Тесты — на синтетике. Перед коммитом проверить diff и текст сообщения на утечки; сообщения коммитов — на английском.
- Go, один модуль: библиотека и утилиты, каждая утилита — отдельная команда (unix way). Внешние зависимости — только с причиной, записанной в замысле.
- Ответ утилиты — для агента: короткий итог и путь к подробностям; ошибка — ненулевой код и где расхождение.
- Гейт и коммит — через graft и glint (`.graft.yaml`, `.glint.yaml`); коммитить и пушить по готовности, релиз — `graft release`.
- Создавать другие репозитории и выбирать окончательные имена утилит — только с пользователем.
- Об утилите агенты узнают строкой в блоке akit `~/.claude/CLAUDE.md` после выпуска, без обязательности и без хуков.
